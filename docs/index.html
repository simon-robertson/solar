ABOUT SOLAR

The model

Solar is an interactive model of the Sun, eight planets and the Moon. Saturn’s seven major moons appear as markers in close views.

Drag to orbit the camera. Scroll to zoom. Select a body for a closer view. Press Tab or use the panel button in the header to show or hide the information panel. Press Space to pause, R to return to today, or Esc to return to the system view.

Scale & orbital model

Sizes and distances are compressed independently for visibility. Planets use JPL’s approximate Keplerian elements for 1800–2050; Earth uses the Earth–Moon barycentre. The Moon follows a simplified ellipse. This is an illustrative orrery, not an ephemeris or an N-body simulation. Dates stop at the model’s limits.

Sources & imagery

Textures by Solar System Scope, licensed under CC BY 4.0. Original 2K maps are used when supported, with a 1K fallback if texture memory allocation fails. Mipmaps are generated on upload. Orbital elements and planetary parameters from NASA / JPL Solar System Dynamics. Stars are procedural. Atmospheres use a single-scattering approximation with illustrative density profiles. Planet textures include artistic colour adjustments and reconstructed terrain.
